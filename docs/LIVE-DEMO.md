# דמו חי (Live demo)

גרסה ציבורית של המערכת שאפשר לשלוח כקישור לבתי ספר לשחייה ולעסקים אחרים. היא רצה כולה על נתונים מומצאים:
אין התחברות אמיתית, אין וואטסאפ אמיתי, אין חיובים וקבלות אמיתיים, ואין שום נתון של רעות.

## מה מקבלים

- **כניסה בלחיצה**: מסך הכניסה מציג את כל התפקידים (בעלים, משרד, מדריך, מלווה הסעה, רואה חשבון, הורה, בית ספר חדש,
  מנהל פלטפורמה), עם שורה שמסבירה מה כל אחד רואה. בלי סיסמה ובלי SMS.
- **בית ספר ניטרלי**: בית הספר נקרא "שחייה בכיף (דמו)" והבעלים "יעל (דמו)". אפשר לשנות את שניהם בהגדרות (למטה).
- **פס "סביבת הדגמה"** בראש כל מסך: כל הנתונים מומצאים ושום הודעה או חיוב לא יוצאים.
- **העבודה ברקע אמיתית**: הודעות נכנסות לתור, השלמות נפתחות, תובנות מתעדכנות, גבייה רצה. רק הספקים מזויפים
  (וואטסאפ, Grow, חשבונית ירוקה, GHL, DNS, והעוזר החכם רץ על גרסת החוקים).
- **איפוס**: הנתונים חוזרים למצב ההתחלתי בכל הפעלה, כל לילה ב-03:00 (שעון ישראל), ובכל רגע דרך קישור האיפוס.

## איך זה בנוי

קונטיינר אחד (`deploy/demo/Dockerfile`) שמריץ את הכול בפנים: Postgres, שרת Inngest, ה-worker ואפליקציית ה-web.
`deploy/demo/start.sh` מרים את מסד הנתונים, בונה אותו מחדש (`pnpm --filter @rswim/seed demo:reset`), מפעיל את
השאר, ומאפס לפי השעה או לפי בקשה. אם תהליך כלשהו נופל, הקונטיינר יוצא והאירוח מפעיל אותו מחדש על נתונים נקיים.
לא צריך Supabase, Vercel או חשבון Inngest בשביל הדמו.

## הקמה ב-Railway (מומלץ, בערך 5 דקות)

1. נכנסים ל-[railway.com](https://railway.com) עם חשבון ה-GitHub (eitanpill). תוכנית Hobby מספיקה (5$ לחודש, כולל
   5$ שימוש; הדמו צורך בערך 1GB זיכרון).
2. **New Project ← Deploy from GitHub repo ← `eitanpill/rswim-os`**. Railway קורא את `railway.json` ובונה את הדמו
   לבד. הבנייה הראשונה לוקחת כמה דקות.
3. בלשונית **Variables** מוסיפים:
   - `RSWIM_DEMO_RESET_KEY` = מחרוזת אקראית ארוכה (אפשר לכתוב `${{secret(32)}}` ו-Railway ימלא לבד). זה המפתח
     לקישור האיפוס. לא שולחים אותו בצ'אט.
   - לא חובה: `RSWIM_DEMO_SCHOOL_NAME` (למשל `גלי הים (דמו)`) ו-`RSWIM_DEMO_OWNER_NAME` (שם פרטי, למשל `דנה`).
4. **Settings ← Networking ← Generate Domain** נותן כתובת כמו `rswim-demo.up.railway.app`. אפשר גם דומיין משלך
   (למשל `demo.leadyourway.co.il`) עם רשומת CNAME שמופיעה שם.
5. זהו. כל מיזוג ל-`main` מעדכן את הדמו אוטומטית. אם ב-Settings ← Source כתוב "Could not load branches", העדכון ידני:
   Deployments ← שלוש הנקודות על הפריסה האחרונה ← Redeploy.

**איפוס לפני פגישה**: פותחים `https://<הכתובת>/dev/reset?key=<RSWIM_DEMO_RESET_KEY>`. תוך פחות מדקה הכול חוזר
להתחלה. אפשר גם ללחוץ Restart ב-Railway.

## מועדון הצלילה החופשית באילת

הדמו תמיד כולל שני ארגונים מומצאים, זה לצד זה: בית הספר לשחייה ומועדון הצלילה החופשית "כחול עמוק אילת (דמו)"
(ועוד מועדון קטן בחיפה, כדי שלמסך הרשת יהיה מה להשוות). למועדון יש מסכים משלו: הגשר של הבעלים, חדר המבצעים,
הדלפק, המדריך במים והאפליקציה של הצוללת. פירוט ב-`docs/FREEDIVING.md`, ותסריט הדגמה ב-`docs/demos/FREEDIVING.md`.

`RSWIM_DEMO_PROFILE=freediving` רק קובע שמסך הכניסה יפתח במועדון הצלילה. ב-Railway: Variables ← מוסיפים
`RSWIM_DEMO_PROFILE` = `freediving` ← Deployments ← שלוש הנקודות על הפריסה האחרונה ← Redeploy. בלי המשתנה השחייה
מופיעה ראשונה, והמועדון מתחתיה.

## אירוח אחר

- **Render**: `render.yaml` בשורש הריפו הוא Blueprint מוכן (New ← Blueprint). צריך תוכנית Standard (2GB), כי
  התוכנית החינמית נרדמת אחרי 15 דקות ואין בה מספיק זיכרון.
- **כל שרת עם Docker**: `docker build -f deploy/demo/Dockerfile -t rswim-demo .` ואז
  `docker run -p 3000:3000 -e RSWIM_DEMO_RESET_KEY=... rswim-demo`.

## הגדרות

| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `RSWIM_DEMO_PROFILE` | `swim` | מה מסך הכניסה מציג ראשון: `swim` (בית הספר לשחייה) או `freediving` (מועדון הצלילה באילת) |
| `RSWIM_DEMO_RESET_KEY` | (אין, הקישור כבוי) | מפעיל את `/dev/reset?key=…` |
| `RSWIM_DEMO_SCHOOL_NAME` | `שחייה בכיף (דמו)` | שם בית הספר לשחייה בדמו |
| `RSWIM_DEMO_OWNER_NAME` | `יעל` | השם הפרטי של בעלת בית הספר לשחייה בדמו |
| `RSWIM_DEMO_RESET_HOUR` | `3` | שעת האיפוס הלילי, שעון ישראל |
| `RSWIM_DEMO_REAL_CLAUDE` + `ANTHROPIC_API_KEY` | כבוי | העוזר החכם ובוט ההורים על Claude אמיתי. עולה כסף, והדמו ציבורי |

## בטיחות

- `start.sh` מוחק כל מפתח של ספק אמיתי שהוגדר בטעות (GHL, Grow, Supabase, Inngest) ומדליק את כל הספקים המזויפים.
- סקריפט האיפוס מוחק את כל מסד הנתונים, ולכן מסרב לרוץ בלי `RSWIM_DEMO_MODE=1` או בסביבת production.
- Postgres ו-Inngest מאזינים רק בתוך הקונטיינר. רק האתר נגיש מבחוץ.
- כל מי שיש לו את הקישור יכול לשנות נתונים (זה דמו). האיפוס הלילי מחזיר הכול.
- זו לא סביבת הייצור של רעות. הייצור יעלה בנפרד, עם Supabase והתחברות אמיתית.
